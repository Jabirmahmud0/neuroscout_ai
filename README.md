# NeuroScout AI 🧠🔍

**NeuroScout AI** is an autonomous, multi-agent research platform designed to automate deep information gathering, synthesis, and reporting. Unlike traditional search engines or simple chatbots, NeuroScout performs iterative discovery to provide comprehensive, cited, and structured knowledge on any topic.

![NeuroScout AI Demo Placeholder](https://via.placeholder.com/1200x600?text=NeuroScout+AI+Interface+Mockup)

## 🚀 Key Features

- **Autonomous Deep Research**: The agent doesn't just "search" once. it performs multiple iterations (3-8) to find deep-web information, identify gaps, and cross-reference sources.
- **Real-time Agent Streaming**: Built with **Server-Sent Events (SSE)**, the platform streams the agent's internal "thinking" and "browsing" steps directly to the UI.
- **High-Fidelity Synthesis**: Automatically generates professional Markdown reports with executive summaries, thematic breakdowns, and academic-style citations.
- **Session Management**: All research sessions are persisted in **MongoDB**, allowing users to revisit, share, and manage their knowledge library.
- **Modern UI/UX**: A premium, responsive interface built with **React 19**, **Tailwind CSS**, and **Framer Motion** for smooth, interactive experiences.

## 🛠️ Tech Stack

### Backend
- **Framework**: [FastAPI](https://fastapi.tiangolo.com/) (Python)
- **Database**: [MongoDB](https://www.mongodb.com/) (with Motor async driver)
- **AI/LLM**: [Gemini Pro](https://deepmind.google/technologies/gemini/) (via Google Generative AI) & [LiteLLM](https://github.com/BerriAI/litellm)
- **Research Tools**: DuckDuckGo Search, BeautifulSoup4, and custom scraping logic.

### Frontend
- **Framework**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) & [Radix UI](https://www.radix-ui.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Markdown Rendering**: [React Markdown](https://github.com/remarkjs/react-markdown) with GFM support.

## 🚦 Getting Started

### 1. Prerequisites
- Python 3.10+
- Node.js 18+
- MongoDB instance (Local or Atlas)
- Gemini API Key

### 2. Backend Setup
```bash
cd backend
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
```
Create a `.env` file in the `backend/` directory:
```env
MONGO_URL=mongodb://localhost:27017
DB_NAME=neuroscout
GEMINI_API_KEY=your_api_key_here
CORS_ORIGINS=http://localhost:3000
```
Run the server:
```bash
python server.py
```

### 3. Frontend Setup
```bash
cd frontend
npm install
```
Create a `.env` file in the `frontend/` directory:
```env
REACT_APP_API_URL=http://localhost:8000
```
Run the app:
```bash
npm start
```

## 🏗️ Architecture

NeuroScout AI operates on a **Controller-Agent** architecture:
1. **The User** submits a query through the React frontend.
2. **FastAPI** initiates a research session and spawns an asynchronous agent.
3. **The Agent** utilizes an LLM (Gemini) to determine search queries, browse web results, and extract relevant text.
4. **SSE** streams each step (Search, Browse, Synthesize) back to the client.
5. **Final Synthesis** takes all gathered intelligence and formats it into the final research report.
